# AI Policy
This is our formal AI policy, in which we require that you read if you use AI tools.

## Development & Contribution Use
We allow that AI can be used for development and contribution purposes, but you are required to check the code it outputs. Do not let the AI vibecode, you must use it as a tool, not a full replacement for **you**. We do not have an opinion on AI use, we just require it to be used as a tool and only a tool. If it works better for you **as a tool**, then use it, if it doesn't, then don't use it. Be responsible with it.

### AI Use Disclosure
We do not require you to disclose use of AI, but we strongly recommend that you do. One way or another, make sure you follow all our **required** policies.

### Commit Messages
We do not allow using fully AI-generated commit messages as they look sloppy and show that you did not guard your agent. **Read and review the code it outputs as stated in the previous policy item, and then WRITE THE COMMIT MESSAGE YOURSELF.** If we find any AI-generated commit messages in your PR or branch, we will require you to review the code and type your own commit message before it can be merged.

## Security Research Use
We allow AI to be used for security research, but we discourage use of AI for security patches themselves.

## Announcements & Social Media
We do not allow use of AI for writing full on announcements and posts. **Just write it yourself, don't be lazy.**

# Future Changes
This policy is subject to change. We will notify everyone publicly if anything is changed here.
